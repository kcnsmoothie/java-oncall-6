# 미션 - 개발자 비상근무

## 목표 : 비상근무표 생성 자동화 시스템

## 구현 기능 목록

### 입력

- 월(숫자)과 시작 요일(일, 월, 화, 수, 목, 금, 토) 정보를 입력
    - 연도는 고려하지 않음
    - 2월은 28일까지만 있다

    ```java
    비상 근무를 배정할 월과 시작 요일을 입력하세요> **5,월**
    ```

- 평일 비상 근무 순서를 입력

    ```java
    평일 비상 근무 순번대로 사원 닉네임을 입력하세요> 준팍,도밥,고니,수아,루루,글로
    ```

- 휴일(토요일, 일요일, 법정공휴일) 비상 근무 순서를 입력

    ```java
    휴일 비상 근무 순번대로 사원 닉네임을 입력하세요> 수아,루루,글로,솔로스타,우코,슬링키,참새,도리,준팍,도밥,고니
    
    ```


---

### 출력

- 비상 근무표 출력
    - 평일이면서 법정공휴일일 경우 요일 뒤에 (휴일) 표기
        - 평일이면서 법정공휴일 : 1/1, 3/1, 5/5, 6/6, 8/15, 10/3, 10/9, 12/25

---

### 조건

- 근무자 닉네임은 중복 X, 최대 5자
- 근무자는 5~35명으로 편성
- 평일 순번, 휴일 순번에 각각 1회 편성
- 연속 2일은 근무 X
    - 다음 근무자와 순서를 바꿔 편성

---

### 기능

- 월과 시작 요일 정보를 입력
    - [x]  쉼표 단위로 파싱
    - [x]  월을 문자열 → 숫자로 변환 및 검증
    - [x]  월이 1 ~ 12 사이인지 검증
    - [x]  시작 요일이 일~월인지 검증
- 평일 비상 근무 순서를 입력
    - [x]  쉼표 단위로 파싱 및 문자열 리스트로 저장
    - [ ]  중복 검사 (테스트 X)
    - [ ]  닉네임 길이가 5자인지 검사 (테스트 X)
- 휴일 비상 근무 순서를 입력
    - [x]  쉼표 단위로 파싱 및 문자열 리스트로 저장
    - [ ]  중복 검사 (테스트 X)
    - [ ]  닉네임 길이가 5자인지 검사 (테스트 X)
    - [ ]  평일 비상 근무 순서와 근무자명이 일치하는지 검사 (테스트 X)
- 해당 월이 몇일까지 있는지 확인하는 기능
    - 28일 : 2
    - 30일 : 4, 6, 9, 11
    - 31일 : 1, 3, 5, 7, 8, 10, 12
- 해당 월이 무슨 요일로 끝나는 지 확인하는 기능
    - 30일 : 30 % 7 == 2
    - 31일 : 31 % 7 == 3
- 근무표를 출력하는 기능
    - 요일도 리스트로 저장해서 n일동안 순회하면서 출력
    - 근무자도 리스트로 저장해서 n일동안 순회하면서 출력

    ```java
    4월 1일 토 오션
    4월 2일 일 로이스
    4월 3일 월 허브
    ```


---

## 예외 처리

- 에러 문구는 반드시 `[ERROR]` 로 시작해야 한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException` 발생
- `[ERROR]` 메시지 출력 후 **해당 입력부터 다시 받는다**
- 예외 메시지

    ```java
    유효하지 않은 입력 값입니다. 다시 입력해 주세요.
    ```


### 유연하게 허용할 예외

- 공백 포함한 정상 입력 (예: `" 1 , 2 , 3 , 4 , 5 , 6 "` → 정상 처리)

### 월과 시작 요일 입력

- 월이 1~12 사이의 숫자가 아닐 때 **(테스트 O)**
- 시작 요일이 월,화,수,목,금,토,일 이 아닐 때

### 평일 순번, 휴일 순번 입력

- 같은 사람을 중복해서 입력했을 경우
